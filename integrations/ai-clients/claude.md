Configure a remote Streamable HTTP MCP server at `https://mcp.join.tl/` and complete
OAuth authorization. Use a client version that supports remote OAuth-protected MCP
servers and structured tool results.

Jointl's optional `io.modelcontextprotocol/skills` capability exposes five workflow
skills. Clients that do not implement the extension can still use standard MCP tools.
For clients that support plugin packages, use the published
[Jointl AI plugin](https://github.com/jointl/jointl-ai-plugin).
