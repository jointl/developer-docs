ChatGPT, Claude, Codex, and generic MCP clients all connect to the same Jointl MCP
server and discover the same permission-dependent tools. Client guides contain only
setup and client-specific behavior; tool details are maintained once in
[the MCP reference](/jointl-mcp/reference).

- [ChatGPT](/integrations/ai-clients/chatgpt)
- [Claude](/integrations/ai-clients/claude)
- [Codex](/integrations/ai-clients/codex)
- [Generic MCP client](/integrations/ai-clients/generic-mcp)

Use OAuth. Never paste a Jointl personal or service-account API key into a hosted AI
client.

Installable Jointl workflow skills and client-package files are available from the
[Jointl AI plugin on GitHub](https://github.com/jointl/jointl-ai-plugin).
