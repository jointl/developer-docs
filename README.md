# Jointl Developer Documentation

Build secure integrations with Jointl using REST, OAuth, MCP, Zapier, and Greenhouse.

- Browse the complete documentation at [docs.join.tl](https://docs.join.tl).
- Download the [Jointl REST API and OAuth OpenAPI contract](https://github.com/jointl/developer-docs/blob/main/specs/openapi/jointl-api-v1.openapi.yaml).
- Download the [Greenhouse integration OpenAPI contract](https://github.com/jointl/developer-docs/blob/main/specs/openapi/greenhouse-v1.openapi.yaml).
- Review the [Jointl MCP guide](https://docs.join.tl/jointl-mcp) and [tool reference](https://docs.join.tl/jointl-mcp/reference).
- Install supported workflow skills from the [Jointl AI plugin](https://github.com/jointl/jointl-ai-plugin).

Examples use fictional data and reserved example domains.
